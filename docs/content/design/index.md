# Design

UX/UI designs, wireframes, and diagrams will live here.

Per [ADR-0008](../documentation/adr/0008-mobile-design-system.md), the mobile app uses platform-native design systems (Material 3 on Android, native HIG/SwiftUI on iOS) rather than a custom component library. Still needed, and not yet started:

- Chetna's brand theme — color palette, typography, iconography, tone of voice — applied on top of each platform's native components.
- The product's genuinely novel screens with no existing design-system answer: the toddler hand-over screen, and the "soft lock" ambient-dark screen (see the [v1 feature set](../brainstorm/v1-feature-set.md)).
