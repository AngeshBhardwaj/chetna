# Design

UX/UI designs, wireframes, and diagrams live here.

Per [ADR-0008](../documentation/adr/0008-mobile-design-system.md), the mobile app uses platform-native design systems (Material 3 on Android, native HIG/SwiftUI on iOS) rather than a custom component library. The brand theme, iconography, and screen mockups are being built out now — see the [design phase plan](../planning/design-phase-plan.md) for the current checklist and [ADR-0013](../documentation/adr/0013-design-prototype-tooling.md) for how the mockup tooling and token pipeline work.
